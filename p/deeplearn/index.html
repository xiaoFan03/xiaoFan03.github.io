张量：深度学习的数据容器

张量（Tensor） 是深度学习底层数据结构，可以简单理解为：存放数字的多维数组。

  1. 张量是深度学习的底层数据结构；
  2. 张量仅能存储数值数据，文本、类别等非数字信息，必须提前转换成数字，才可以存入张量；
  3. 在 PyTorch 中，无论什么原始数据，都需要封装成张量，才能够送入网络计算。

例：如一张彩色图片，本质就是数字组成的三维张量；一句话经过编码处理之后，同样会转化为张量。

创建张量

  1. 基本方式tensor() / Tensor() / IntTensor()、FloatTensor()，直接将数字列表转换为张量。
  2. 线性张量：生成均匀分布的一串数字
  • range(start,end,step)：按照步长生成数字，不包含 end（包左不包右）；
  • linspace(start,end,steps)：在起止区间内，生成指定个数元素，包含首尾数值。
  1. 随机张量：生成随机数字的张量，常用于参数初始化
  • rand()、randn()、randint()：生成不同分布的随机数；

随机种子：initial_seed 获取当前随机种子；manual_seed() 设置随机种子。

设置相同种子，每次运行可以得到完全一致的随机数，方便实验结果复现。

  1. 指定值张量：快速生成全 0、全 1 张量ones() / zeros() / full()；还有ones_like()、zeros_like()，参照另一个张量的形状，生成相同尺寸的全 1 / 全 0 张量。
  2. 指定元素值类型：修改张量内部数字的数据类型
  • 张量对象.type(目标类型)
  • 快捷写法：half()、short()、int()、long()、float()、double()

张量类型转换

  1. 张量 ↔ ndarray（Numpy 数组）
  • 张量转 numpy 数组：张量.numpy()，默认共享内存，修改其中一个，另一个同步变化；增加.copy()之后不再共享内存；
  • numpy 数组转张量：torch.from_numpy(数组) 共享内存；torch.tensor(数组) 不共享内存。
  1. 张量 → 标量（单个数字）：张量.item()，仅张量内只有 1 个元素时才能够使用。

张量数值计算

  • 基础四则运算：add、sub、mul、div。不带下划线例如add()，不修改原始张量，返回全新张量；带下划线add_()代表原地运算，直接修改原始张量。日常编码直接使用运算符 + - * /。
  • 点乘运算：对应位置数字一一相乘，要求两个张量形状完全一致；写法为*或者.mul()。
  • 矩阵乘法：神经网络最核心运算！要求前一个张量的列数等于后一个张量的行数；语法为@或者.matmul()。

⚠️注意区分：点乘是元素位置一一相乘；矩阵乘法是线性代数标准矩阵相乘，二者完全不同。

张量运算函数

sum(dim)、mean(dim)、log、pow、sqrt、exp、max、min。

参数dim代表运算执行的维度；不传dim时，会针对张量全部元素整体求和 / 求平均，输出单个标量张量。

张量索引操作

索引用于取出张量中的部分数据，逻辑和 Python 列表切片相似：

  1. 简单行列索引：tensor[0]获取第一行；tensor[:,0]获取第一列；
  2. 范围索引：[行起始:行结束:步长, 列起始:列结束:步长]；
  3. 列表索引、布尔索引；
  4. 多维索引：
    • dim=0 代表 0 轴，也就是最外层维度；
    • dim=-1 代表最后一维，即最内层维度，写代码中使用频率很高。

张量形状操作

用于修改张量的维度与外形，约束条件：修改前后张量的元素总数量必须相等。

  • reshape：改变张量维度排布，不改动原始数据；
  • squeeze / unsqueeze：删除 / 增加长度为 1 的维度，常用来适配网络输入格式；
  • transpose / permute：交换维度顺序。transpose仅可以交换两个维度；permute能够一次性调整全部维度顺序。

张量的拼接：cat和stack

  1. cat / concat
    • 规则：不参与拼接的维度必须保持相同，正在拼接的维度大小不作限制；
    • 特点：拼接完成后张量维度数量不变，不会新增维度。
  2. stack
    • 规则：参与拼接的全部张量形状必须完全一模一样；
    • 特点：产生一个全新维度（升维），拼接后张量维度数量 + 1。

通俗理解：cat 是在现有的维度上将多组数据接长；stack 是新增一层，把多个张量堆叠在一起。

深度学习

神经网络概念

人工神经网络（Artificial Neural Network， 简写为ANN）也简称为神经网络（NN），是一种模仿生物神经网络结构和功能的计算模型。由多个互相连接的人工神经元（也称为节点）构成，可以用于处理和学习复杂的数据模式，尤其适合解决非线性问题。神经网络是模仿生物神经网络结构与功能的计算模型，搭建神经网络，本质就是构建神经元。

神经元如下图所示：

神经元内部过程：输入数据先完成线性求和，将结果送入激活函数，计算得到激活输出值。

神经网络构成

  1. 输入层：接收输入x的层，如图像、文本、声音等。每一个输入特征对应一个神经元，负责把数据传递给下一层网络。

  2. 输出层：输出预测结果y的层，神经元会根据具体任务输出最终预测。

  3. 隐藏层：处于输入层、输出层中间的全部层。隐藏层的数量决定神经网络的深度；内部神经元完成加权运算与激活函数处理，将结果传递到下一层。

神经网络特点：

  • 同一层的神经元之间没有连接
  • 第N层的每个神经元和第N-1层的所有神经元相连（这就是Fully Connected的含义)，这就是全连接神经网络（FCNN）
  • 全连接神经网络接收的样本数据是二维的，数据在每一层之间需要以二维的形式传递
  • 第N-1层神经元的输出就是第N层神经元的输入
  • 每个连接都有一个权重值（w系数和b系数）

神经网络主要分为三大类：

  1. ANN（人工神经网络）：最基础的全连接神经网络，每一层神经元都和下一层全部神经元相连；
  2. CNN（卷积神经网络）：多用于图像任务，擅长提取图片的局部特征；
  3. RNN（循环神经网络）：专门处理序列数据，例如文本语句、时间序列。

激活函数

激活函数用于对每层的输出数据进行变换, 进而为整个网络注入了非线性因素。此时, 神经网络就可以拟合各种曲线。如果不使用激活函数，整个网络虽然看起来复杂，其本质还相当于一种线性模型

常见的激活函数

Sigmoid 函数：可以将任意输入映射到区间\((0,1)\)；当输入小于 - 6 或者大于 6 时，导数趋近于 0，梯度更新缓慢甚至发生梯度消失；仅在\([-6,6]\)区间梯度变化明显。

备注：Sigmoid 多用于输出层，适配二分类任务；如果放在隐藏层，网络层数建议不超过 4 层。

Tanh 函数：将任意输入映射至\((-1,1)\)；输入小于‑3 或者大于 3，导数趋近于 0，会出现梯度下降缓慢、梯度消失；\([-3,3]\)区间梯度效果明显。

备注：Tanh 大多用于隐藏层。

Relu 函数：小于 0 的输入直接映射为 0，大于 0 的输入保持原值不变。

备注：Relu 一般用于隐藏层。

Softmax 函数：输出各个类别的预测概率，全部类别概率累加等于 1；选取概率最大值对应的类别作为最终预测结果。

备注：Softmax 大多放在输出层，解决多分类任务。

若初始化的数值不合理，模型训练从一开始就会走向错误方向，后续调参很难挽回效果

import torch
import torch.nn as nn

class myMOdel(nn.Module):
    def __init__(self):
        #a、初始化父类
        super().__init__()
        #b、设置属性值

        #c、定义神经网络结构：隐藏层基层、输出层是怎样的
        #定义隐藏层
        self.linear1 = nn.Linear(3,3 )
        self.linear2 = nn.Linear(3,2)
        #定义输出层
        self.output = nn.Linear(2,2)

        #d、参数初始化：w、b如何进行初始化
        nn.init.xavier_normal_(self.linear1.weight)     #w初始化
        nn.init.zeros_(self.linear1.bias)               #b初始化

        nn.init.xavier_normal_(self.linear2.weight)
        nn.init.zeros_(self.linear2.bias)

    # forward：前向传播，将数据送入搭建好的网络模型中，对模型进行训练
    def forward(self, data):
        # 数据经过第一层隐藏层
        # 线性求和
        # linear1_result = self.lineart(data)
        # 激活函数
        # data = torch.sigmoid(linear1_result)
        data = torch.sigmoid(self.linear1(data))

        #第二层隐藏仓
        data = torch.sigmoid(self.linear2(data))

        #经过输出层得到输出结果
        return torch.softmax(self.output(data), dim=-1)

损失函数

损失函数概念

在深度学习中, 损失函数是用来衡量模型参数质量的函数， 衡量的方式是比较网络输出（预测值）和真实输出（真实值）的差异。

分类任务损失函数

深度学习的分类任务中使用最多的是交叉熵损失函数，在多分类任务通常使用softmax将logits转换为概率的形式，所以多分类的交叉熵损失也叫做softmax损失。

回归的损失函数总结：
    1- L1损失

        使用：较少使用，相对比MAE用的多些。一般作为正则化下添加到其他损失函数中
    3- SmoothL1损失
        特点：集成了L1损失和L2损失，而且避免了它们的确定
        使用：经常使用

神经网络优化方法

在进行模型训练时，有三个基础的概念：

  1. Epoch: 使用全部数据对模型进行以此完整训练，训练次数
  2. Batch: 使用训练集中的小部分样本对模型权重进行以此反向传播的参数更新，每次训练每批次样本数量
  3. Iteration: 使用一个 Batch 数据对模型进行一次参数更新的过程，每次训练批次数

在深度学习中，梯度下降的几种方式的根本区别就在于Batch Size不同。

反向传播

多层神经网络的学习能力比单层网络强得多。想要训练多层网络，需要更强大的学习算法。反向传播算法是其中最杰出的代表，它是目前最成功的神经网络学习算法。BP算法不仅可用于多层前馈神经网络，还可以用于其他类型的神经网络。通常说BP网络时，一般是指用BP算法训练的多层前馈神经网络。这就需要了解两个概念：

  1. 正向传播：指的是数据通过网络从输入层到输出层的传递过程。这个过程的目的是计算网络的输出值（预测值），从而与目标值（真实值）比较以计算误差。
  2. 反向传播：指的是计算损失函数相对于网络中各参数（权重和偏置）的梯度，指导优化器更新参数，从而使神经网络的预测更接近目标值。

反向传播算法利用链式法则对神经网络中的各个节点的权重进行更新。

梯度下降优化方法

梯度下降算法中，可能会碰到以下情况：

  • 碰到平缓区域，梯度值较小，参数优化变慢
  • 碰到 “鞍点” ，梯度为0，参数无法优化
  • 碰到局部最小值，参数不是最优

对于这些问题, 出现了一些对梯度下降算法的优化方法：

Momentum动量法：只对梯度值grad来进行优化

Momentum 通过指数加权平均法，累计历史梯度值，进行参数更新，越近的梯度值对当前参数更新的重要性越大。

import torch
import torch.nn

def momentum_demo():
    # 初始化权重值
    w = torch.tensor([1.0],requires_grad=True,dtype=torch.float32)

    # 自定义损失函数
    criterion = (w**2)/2

    # 创建优化器对象，作用：1-计算梯度；2-自动更新权重
    optimizer = torch.optim.SGD([w],lr=0.1,momentum=0.9)

    # 反向传播计算梯度
    # 梯度清零
    optimizer.zero_grad()
    # 反向传播
    criterion.sum().backward()
    # 更新权重
    optimizer.step()
    print(f"第1次，梯度的结果{w.grad}")

    # 第二次
    criterion = (w ** 2) / 2
    # 反向传播计算梯度
    # 梯度清零
    optimizer.zero_grad()
    # 反向传播
    criterion.sum().backward()
    # 更新权重
    optimizer.step()
    print(f"第2次，梯度的结果{w.grad}")

if __name__ == '__main__':
    # 动量法
    momentum_demo()

AdaGrad：梯度为0，只对学习率lr进行优化

AdaGrad 通过对不同的参数分量使用不同的学习率，AdaGrad 的学习率总体会逐渐减小，因为 AdaGrad 认为：在起初时，我们距离最优目标仍较远，可以使用较大的学习率，加快训练速度，随着迭代次数的增加，学习率会逐渐下降。

def AdaDemo():
    # 初始化权重参数
    w = torch.tensor([1.0], requires_grad=True, dtype=torch.float32)
    loss = ((w ** 2) / 2.0).sum()
    # 实例化adagrad优化方法
    optimizer = torch.optim.Adagrad([w], lr=0.01)
    # 第1次更新，计算梯度，并对参数进行更新
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
    print('第1次: 梯度w.grad: %f, 更新后的权重:%f' % (w.grad.numpy(), w.detach().numpy()))
    # 第2次更新，计算梯度，并对参数进行更新
    # 使用更新后的参数机选输出结果
    loss = ((w ** 2) / 2.0).sum()
    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
    print('第2次: 梯度w.grad: %f, 更新后的权重:%f' % (w.grad.numpy(), w.detach().numpy()))

def RMSPDemo():
    # 1 初始化权重参数
    w = torch.tensor([1.0], requires_grad=True, dtype=torch.float32)
    loss = ((w ** 2) / 2.0).sum()
    # 2 实例化优化方法：RMSprop算法，其中alpha对应beta
    optimizer = torch.optim.RMSprop([w], lr=0.01, alpha=0.9)
    # 3 第1次更新 计算梯度，并对参数进行更新
    optimizer.zero_grad()
